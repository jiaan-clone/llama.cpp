## 习题1
 闭卷画图**: 从 `token id` 开始, 画到 `next token id`; 在 Attention、FFN、logits、sampler 和 decode 循环处标出输入输出 shape。

答：
```text
符号：
N    = 本次 llama_decode 输入的 token 数
S    = 当前 KV cache 中的总上下文长度
d    = hidden size
H    = attention head 数
Hkv  = KV head 数（GQA 时 Hkv <= H）
dh   = 每个 head 的维度，通常 d = H * dh
dff  = FFN 中间层维度
V    = 词表大小
L    = Transformer block 层数


输入 token ids
[ N ]                         例如 prefill 时 N=P；生成阶段通常 N=1
  │
  │ token embedding 查表
  ▼
X0: hidden states
[ N, d ]
  │
  │
  ├──────────────────────── Transformer Block 1 ────────────────────────┐
  │                                                                      │
  │  RMSNorm                                                            │
  │  [ N, d ]                                                           │
  │    │                                                                 │
  │    ├─ Wq ──> Q [ N, H,   dh ]                                       │
  │    ├─ Wk ──> K [ N, Hkv, dh ] ──> 写入 KV cache                    │
  │    └─ Wv ──> V [ N, Hkv, dh ] ──> 写入 KV cache                    │
  │                                                                      │
  │                    KV cache（本层）                                 │
  │                    K/V: [ S, Hkv, dh ]                              │
  │                              │                                       │
  │  RoPE(Q, K)                 │                                       │
  │    │                         │                                       │
  │    ▼                         ▼                                       │
  │  Attention scores: Q @ K^T                                           │
  │  [ H, N, S ]              # GQA 中 K/V head 按组供多个 Q head 使用 │
  │    │                                                                 │
  │  causal mask + softmax                                               │
  │  attention weights [ H, N, S ]                                      │
  │    │                                                                 │
  │  weights @ V                                                        │
  │  attention output [ H, N, dh ]                                      │
  │    │                                                                 │
  │  合并 heads + 输出投影 Wo                                           │
  │  attention result [ N, d ]                                          │
  │    │                                                                 │
  │  residual add: X + attention result                                 │
  │  [ N, d ]                                                           │
  │    │                                                                 │
  │  RMSNorm                                                            │
  │  [ N, d ]                                                           │
  │    │                                                                 │
  │  FFN / SwiGLU                                                       │
  │  gate projection: [ N, d ] -> [ N, dff ]                            │
  │  up projection:   [ N, d ] -> [ N, dff ]                            │
  │  SiLU(gate) * up:             [ N, dff ]                            │
  │  down projection:              [ N, d ]                              │
  │    │                                                                 │
  │  residual add                                                        │
  │  X1: [ N, d ]                                                       │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘
  │
  │ 重复 Block 2 ... Block L
  ▼
XL: final hidden states
[ N, d ]
  │
  │ final RMSNorm
  ▼
[ N, d ]
  │
  │ LM head / 输出投影：W_vocab
  ▼
logits
[ N, V ]                       每个输入位置对词表中 V 个 token 的未归一化分数
  │
  │ 取最后一个有效位置
  ▼
last-token logits
[ V ]
  │
  │ sampler：greedy / temperature / top-k / top-p 等
  ▼
next token id
[ 1 ]                          一个整数，例如 29871
```

```text
decode 循环：

prompt token ids [ P ]
        │
        ▼
llama_decode(batch.n_tokens = P)
        │
        ├─ 建立 prompt 的 KV cache：S = P
        └─ 取得最后位置 logits [ V ]
                    │
                    ▼
              sampler -> T1 [ 1 ]
                    │
                    ▼
llama_decode(batch.n_tokens = 1，输入 T1)
        │
        ├─ 复用已有 KV cache
        ├─ 新增 T1 的 K/V：S = P + 1
        └─ 得到 logits [ V ]
                    │
                    ▼
              sampler -> T2 [ 1 ]
                    │
                    ▼
                 持续循环，直到 EOG 或达到 n_predict
```

长 prompt 超过 `n_batch` 时，`prompt token ids [P]` 会分成多次 `llama_decode`；但生成阶段仍通常是每轮输入一个新 token。


## FQA
1. 将 RMSNorm 、 RoPE 、GQA 、FFN 、 SwiGLU 、 SiLU(gate) 的全称 与中文翻译列出来
| 缩写 / 名称 | 英文全称 | 中文翻译 |
|---|---|---|
| RMSNorm | Root Mean Square Normalization | 均方根归一化 |
| RoPE | Rotary Positional Embedding | 旋转位置编码 |
| GQA | Grouped-Query Attention | 分组查询注意力 |
| FFN | Feed-Forward Network | 前馈网络 |
| SwiGLU | Swish-Gated Linear Unit | Swish 门控线性单元 |
| SiLU | Sigmoid Linear Unit | Sigmoid 线性单元 |
| `SiLU(gate)` | 将 gate 分支的值应用 SiLU 激活函数 | 对门控分支施加 SiLU 激活 |

补充：`SwiGLU` 常见形式为：

```text
FFN(x) = W_down( SiLU(xW_gate) ⊙ (xW_up) )
```

其中 `⊙` 表示逐元素相乘；`gate` 是门控投影的输出，不是一个独立模型组件。

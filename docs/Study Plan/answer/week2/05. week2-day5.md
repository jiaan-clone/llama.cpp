# week2 day5

## 习题1
闭卷列出 `load_tensors()` 前必须已完成的三件事。

答：

`load_tensors()` 前必须完成的三件事是：

1. **确定模型架构并创建正确的模型子类。** loader 从 GGUF 的
   `general.architecture` 得到 `llm_arch`；当前模型由 `qwen2` 映射为
   `LLM_ARCH_QWEN2`，再由模型工厂创建 `llama_model_qwen2`。只有先确定架构，
   `load_tensors()` 才能通过多态调用正确的 `load_arch_tensors()`，并用正确的
   tensor 名称规则解释 `weights_map`。
2. **加载 hparams。** `load_hparams()` 先读取通用参数，再调用
   `load_arch_hparams()` 补充架构专用参数。`n_layer_all` 决定创建多少层，
   `n_embd`、`n_ff`、`n_head` 和 `n_head_kv` 等决定权重 shape；没有这些值就
   无法声明 tensor、规划 layer placement 或计算 buffer 大小。
3. **加载 vocab。** `load_vocab()` 从 GGUF metadata 建立 tokenizer/vocab。
   `load_tensors()` 中的 `LLAMA_LOAD_LOCALS` 使用 `vocab.n_tokens()` 得到
   `n_vocab`，以确定 `token_embd.weight`、`output.weight` 等 tensor 的词表维度。

可以压缩为：

```text
arch/model class ready
  -> hparams ready
  -> vocab ready
  -> load_tensors()
```

在实际固定流程中，`llama_prepare_model_devices()` 也已经先于上述加载阶段完成，
为后续 tensor placement 准备设备列表；但本题要求回忆的三项数据依赖是
**架构、hparams、vocab**。

## 习题2
读 Llama tensor 声明**：阅读 [`src/models/llama.cpp`](../../../..//src/models/llama.cpp) 的 `load_arch_tensors()`，只覆盖 token embedding、output norm/output、layer 0 的 norm、Q/K/V/output 和 FFN gate/up/down。将 `create_tensor(..., { ... })` 的 `ne[]` 顺序逐项抄入 Day 1 表，再在相邻列写逻辑 shape。不要仅凭矩阵数学转置它；以源码和 GGUF 输出为准。

答：

先定义源码中的维度：

```text
D  = n_embd
V  = n_vocab
I  = n_ff
Dq = n_embd_head_k * n_head   （普通 Llama 中通常等于 D）
Dk = n_embd_k_gqa             （常见为 KvH * key head dim）
Dv = n_embd_v_gqa             （常见为 KvH * value head dim）
```

`create_tensor()` 的 initializer 是 GGML `ne[]` 顺序，即先写 `ne[0]`，再写
`ne[1]`。对这里的二维线性权重，GGML 保存顺序可写为 `[in, out]`，而常用的
Transformer 逻辑矩阵 shape 写为 `[out, in]`。这个对应关系来自源码声明，并由
GGUF 输出验证，不是只根据矩阵习惯猜测。

### 源码声明与实际 GGUF shape

| 权重语义 | GGUF 名称（`i=0`） | Llama `create_tensor()` 的 `ne[]` | 逻辑 shape `[out, in]` | 当前模型 GGUF `ne[]` | 当前逻辑 shape |
| --- | --- | --- | --- | --- | --- |
| token embedding | `token_embd.weight` | `{D, V}` | `[V, D]` | `(1536, 151936)` | `[151936, 1536]` |
| output norm | `output_norm.weight` | `{D}` | `[D]` | `(1536)` | `[1536]` |
| output projection | `output.weight` | `{D, V}` | `[V, D]` | `(1536, 151936)` | `[151936, 1536]` |
| layer 0 attention norm | `blk.0.attn_norm.weight` | `{D}` | `[D]` | `(1536)` | `[1536]` |
| Q projection | `blk.0.attn_q.weight` | `{D, Dq}` | `[Dq, D]` | `(1536, 1536)` | `[1536, 1536]` |
| K projection | `blk.0.attn_k.weight` | `{D, Dk}` | `[Dk, D]` | `(1536, 256)` | `[256, 1536]` |
| V projection | `blk.0.attn_v.weight` | `{D, Dv}` | `[Dv, D]` | `(1536, 256)` | `[256, 1536]` |
| attention output | `blk.0.attn_output.weight` | `{Dq, D}` | `[D, Dq]` | `(1536, 1536)` | `[1536, 1536]` |
| layer 0 FFN norm | `blk.0.ffn_norm.weight` | `{D}` | `[D]` | `(1536)` | `[1536]` |
| FFN gate | `blk.0.ffn_gate.weight` | `{D, I}` | `[I, D]` | `(1536, 8960)` | `[8960, 1536]` |
| FFN up | `blk.0.ffn_up.weight` | `{D, I}` | `[I, D]` | `(1536, 8960)` | `[8960, 1536]` |
| FFN down | `blk.0.ffn_down.weight` | `{I, D}` | `[D, I]` | `(8960, 1536)` | `[1536, 8960]` |

GGUF 工具实际以四个槽位输出，例如 token embedding 是
`ne=(1536, 151936, 1, 1)`；表中省略未使用的尾部 `1`。一维 norm 同理，其工具
输出为 `(1536, 1, 1, 1)`，有效 shape 记为 `(1536)`。

### Q/K/V helper 的真实分支

`src/models/llama.cpp` 并未直接写三次 Q/K/V 的 `create_tensor()`，而是调用：

```cpp
create_tensor_qkv(
    layer, i,
    n_embd,
    n_embd_head_k * n_head,
    n_embd_k_gqa,
    n_embd_v_gqa,
    0);
```

`create_tensor_qkv()` 先尝试可选的合并权重：

```text
attn_qkv.weight ne[] = {D, Dq + Dk + Dv}
```

若 GGUF 中没有合并 tensor，才按上表声明独立 Q、K、V：

```text
attn_q.weight ne[] = {D, Dq}
attn_k.weight ne[] = {D, Dk}
attn_v.weight ne[] = {D, Dv}
```

当前模型的 GGUF 明确包含独立的 `blk.0.attn_q.weight`、
`blk.0.attn_k.weight` 和 `blk.0.attn_v.weight`，所以实际走独立 Q/K/V 分支。

### 两个边界说明

1. `output.weight` 带有 `TENSOR_NOT_REQUIRED`。若文件没有独立 output 权重，
   Llama loader 会用 `token_embd.weight` 创建 duplicated tensor，实现 tied
   embedding；当前 GGUF 有独立的 `output.weight`，shape 仍为 `{D, V}`。
2. 题目要求阅读 Llama 声明，而当前文件的实际架构是 Qwen2。Qwen2 的
   `load_arch_tensors()` 对表中这些核心权重采用相同的 `ne[]` 方向；当前参数
   `D=1536`、`V=151936`、`I=8960`、`Dq=1536`、`Dk=Dv=256`，因此可以用该
   GGUF 输出逐项验证表格。Qwen2 额外的可选 bias 不在本题范围内。

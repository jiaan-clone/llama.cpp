# week2 day2
## 习题1
不看 Day 1 笔记，写出模型的 `D/H/KvH/I/V/L` 实际数值或标出尚未找到的项。
答：

本题模型为 `deepseek-r1-1.5b-f16.gguf`（Qwen2 架构）。从 GGUF metadata 与 tensor shape 可得到：

| 符号 | 含义 | 实际值 | 对应字段或依据 |
| --- | --- | ---: | --- |
| `D` | hidden size / embedding length | `1536` | `qwen2.embedding_length`；`token_embd.weight` 的 hidden 维 |
| `H` | Query attention head 数 | `12` | `qwen2.attention.head_count` |
| `KvH` | Key/Value head 数 | `2` | `qwen2.attention.head_count_kv` |
| `I` | FFN intermediate size | `8960` | `qwen2.feed_forward_length`；`ffn_gate/up.weight` 的中间维 |
| `V` | vocabulary size | `151936` | `token_embd.weight` 的词表维 |
| `L` | Transformer block/layer 数 | `28` | `qwen2.block_count` |

补充：`Dh = D / H = 1536 / 12 = 128`；因此 K/V 总维度为 `KvH * Dh = 2 * 128 = 256`。
